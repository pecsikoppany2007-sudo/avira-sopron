# Avira Move & Relax – bemutató oldal

Avira Café és Avira Pilates, 9400 Sopron, Táncsics M. u. 68. (a régi vasáruházban, a GYMTronic mellett).

- `site/` – a kész oldal (Netlify: publish = site, minden push a main ágra élesít)
- `forras/` – képfeldolgozás (`img.py`), mélységtérkép a nyitóképhez (`melyseg.py`), ecsetvonásos kör útvonala (`enso.txt`)
- `teszt/` – Playwright-ellenőrzések (`shot.js`, `gate.js`, `fit.js`, `interact.js`, `reduced.js`, `perf.js`); a helyi szerver: `cd site && python3 -m http.server 8811`

Fotók: az Avira Move & Relax Instagram-oldalairól (avira_sopron, avira.pilates). Minden kép és szöveg után `?v=N`, kiadáskor növelni kell.
